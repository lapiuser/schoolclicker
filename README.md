# БИТВА ШКОЛ — Россия R3

Единый production-ready проект для локального теста, Render и Timeweb.

## Каталог

Исходный национальный CSV содержит 17,951 записи и 296 городов. В национальном файле есть 104 строки для Калининграда; они намеренно не импортируются. Для Калининграда используются только 75 заведений из старой версии сайта с сохранёнными фотографиями.

Итоговый каталог после импорта: 17,922 активных объекта.

Для остальных городов фото не генерируются и не скачиваются автоматически. Администратор может вручную добавить школу и фотографию через `/admin`.

## Защита рейтинга

- 800 принятых кликов за скользящие 60 секунд.
- До 800 кликов в одной клиентской пачке.
- Клиенты отправляют накопившиеся клики примерно раз в 5 секунд.
- 800/5s burst limit.
- Вторичный лимит 800/мин и 800/5s по fingerprint IP-подсети + User-Agent, чтобы замена cookie не создавала новую квоту.
- Ограничение частоты запросов по IP-подсети.
- Сетевой дневной safety cap.
- Idempotency по `request_id`.
- Server-side Cloudflare Turnstile validation.
- Журнал abuse-событий и блокировка identity в админке.

Это не делает распределённый DDoS физически невозможным; для production нужен отдельный сетевой DDoS/CDN-слой.

## Статистика

- Всего посетителей — число зафиксированных сервером visitor identity за всё время.
- Сейчас на сайте — активные identity.
- Всего кликов — только реальные засчитанные клики.
- Школ играет — только активные школы с `real_clicks > 0`.
- График кликов/с — последние 5 секунд.

Важно: веб-сайт не может надёжно узнать, где один физический человек, а где два человека с одного IP. Статистика посетителей поэтому считает серверные идентификаторы, а не паспортное число людей.

## Локальный тест

Windows:

```text
run_windows.bat
```

Для телефона в той же Wi-Fi сети:

```text
run_windows_lan.bat
```

Оба скрипта используют официальный тестовый Turnstile и попросят пароль админки без сохранения его в файле.

## Render

Подробно: `RENDER_DEPLOY.md`.

`render.yaml` создаёт Web Service + Free Postgres.

Render Free предназначен для тестирования: Web Service может засыпать после простоя, файловая система эфемерная, а Free Postgres имеет ограничение 1 GB и срок жизни 30 дней.

## Timeweb

Подробно: `TIMEWEB_DEPLOY.md`.

Production-схема:

```text
Интернет
  ↓
DDoS/CDN (при необходимости)
  ↓
Caddy :80/:443
  ↓
FastAPI :8000
  ↓
PostgreSQL
```

PostgreSQL не открывается наружу. Фотографии хранятся на постоянном диске VDS.
